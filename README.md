# AgriSmartRwanda 🌾\n\n> AI-powered agricultural ecosystem for Rwandan farmers with crop recommendations, disease detection, yield prediction, and market access.\n\n## 🚀 Quick Start\n\n### Using Docker Compose\n\n```bash\ndocker-compose up -d\n```\n\nAccess:\n- Frontend: http://localhost:3000\n- Backend API: http://localhost:5000\n- MongoDB: localhost:27017\n- Redis: localhost:6379\n\n### Manual Setup\n\n**Backend**\n```bash\ncd backend\nnpm install\ncp .env.example .env\nnpm run dev\n```\n\n**Frontend**\n```bash\ncd frontend\nnpm install\ncp .env.example .env\nnpm run dev\n```\n\n## 📋 Tech Stack\n\n- **Frontend**: Next.js 14, TypeScript, Tailwind CSS\n- **Backend**: Node.js, Express.js, MongoDB, Redis\n- **Authentication**: JWT Tokens\n- **Real-time**: Socket.io\n- **ML/AI**: TensorFlow, scikit-learn\n\n## ✨ Features\n\n✅ User Authentication (Register/Login)\n✅ Farmer Profiles & Ranking\n✅ AI Crop Recommendations\n✅ Disease Detection with CV\n✅ Yield Predictions\n✅ Market Pricing & Listings\n✅ Achievements & Gamification\n✅ Real-time Notifications\n✅ Multi-language Support\n✅ Offline Functionality\n\n## 📚 API Endpoints\n\n**Auth**\n- `POST /api/v1/auth/register` - Register\n- `POST /api/v1/auth/login` - Login\n- `POST /api/v1/auth/refresh` - Refresh token\n\n**Farmers**\n- `GET /api/v1/farmers` - List farmers\n- `GET /api/v1/farmers/:id` - Get farmer\n- `POST /api/v1/farmers` - Create/update profile\n\n**Crops**\n- `GET /api/v1/crops` - List crops\n- `GET /api/v1/crops/:id` - Get crop\n\n**Recommendations**\n- `GET /api/v1/recommendations` - Get recommendations\n\n**Diseases**\n- `GET /api/v1/diseases` - List diseases\n- `GET /api/v1/diseases/detections` - Get detections\n\n**Market**\n- `GET /api/v1/market/prices` - Market prices\n- `GET /api/v1/market/listings` - Product listings\n\n## 🔧 Configuration\n\n### Backend (.env)\n```\nPORT=5000\nMONGODB_URI=mongodb://localhost:27017/agrismarten\nJWT_SECRET=your-secret-key\nREDIS_URL=redis://localhost:6379\nFRONTEND_URL=http://localhost:3000\n```\n\n### Frontend (.env.local)\n```\nNEXT_PUBLIC_API_URL=http://localhost:5000/api/v1\nNEXTAUTH_SECRET=your-secret-key\nNEXTAUTH_URL=http://localhost:3000\n```\n\n## 📂 Project Structure\n\n```\nAgriSmartRwanda/\n├── backend/\n│   ├── src/\n│   │   ├── models/          # MongoDB schemas\n│   │   ├── routes/          # API endpoints\n│   │   ├── middleware/      # Auth, validation\n│   │   ├── utils/           # Helpers\n│   │   ├── config/          # DB, Redis\n│   │   └── index.js         # Entry point\n│   └── package.json\n├── frontend/\n│   ├── src/\n│   │   ├── app/             # Next.js pages\n│   │   ├── components/      # React components\n│   │   ├── lib/             # Utilities\n│   │   └── styles/          # CSS/Tailwind\n│   └── package.json\n├── docker-compose.yml\n└── README.md\n```\n\n## 🧪 Testing\n\n**Backend**\n```bash\ncd backend\nnpm test\n```\n\n**Frontend**\n```bash\ncd frontend\nnpm test\n```\n\n## 📝 License\n\nMIT\n\n## 🤝 Contributing\n\nSee CONTRIBUTING.md for guidelines\n\n## 📞 Support\n\nFor issues, questions, or suggestions, please open an issue on GitHub.
